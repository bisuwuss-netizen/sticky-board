# The Journey · 便利贴白板

一个本地优先的 Mac 工作台：固定 2400×1600 画板、多画板、彩色便利贴、任务管理和结构化文本都在同一个界面完成。数据默认只保存在本机。

## 功能

- 便利贴两种类型：**文本贴**（富文本，支持粗体 / 斜体 / 下划线 / 删除线 / 行内代码 / 链接 / 列表 / 标题 / 引用 / 代码块）与 **清单贴**（可勾选事项）
- 固定尺寸画板：每个画板都是 2400×1600，新建画板也使用同一尺寸，拖动和缩放不会跑出边界
- 文字排版：段落、换行、无序/有序列表、标题、引用、粗体、斜体、下划线、删除线、行内代码、链接；代码块支持关键字、字符串、数字和注释高亮，并识别 ``` 围栏代码块
- 画布工具：真正的框选、多选、锁定、置顶/置底、连接线（箭头可选）、自动吸附、矩形、圆形（含填充色与文字标签）
- 任务：状态、优先级（无/低/中/高）、标签、截止日期、子任务状态
- 界面分层：工具栏只保留 5 个入口（+便利贴 / 搜索 / 工具 / 视图 / ⋯），绘图工具与导入导出分别收进两个弹出层；属性面板默认只显示状态/优先级/截止，其余收进「更多属性」
- 今天页：今日到期与逾期（可一键完成）、进行中清单，一个入口开始一天
- 视图：今天、真看板（拖拽改状态）、跨画板全局搜索一键跳转并自动居中定位、统计仪表盘（含子项完成口径）
- 数据安全：撤销/重做（⌘Z / ⇧⌘Z）、便利贴与画布元素统一回收站（可恢复/清空）、JSON 导入/导出、多选批量编辑、文件级自动备份；存档损坏时自动回落到影子备份并把坏档另存为 `stickyboards-v1-corrupt`，不会静默清空
- 快捷键：⌘Z 撤销、⇧⌘Z 重做、⌘D 复制、⌘A 全选、Delete 移入回收站、方向键微调（Shift 大步长）、Esc 取消工具；右下角 ? 按钮随时查看（前 3 次启动自动展示）
- 可访问性：贴纸 / 画板 / 调色板格子 / 面板列表项都能 Tab 聚焦并带中文 `aria-label`（贴纸名 = 类型 + 标题 + 状态 / 优先级 / 截止）；Enter 选中、空格加减选；全屏面板是 `role="dialog"` 且打开时把焦点带进去（搜索面板例外，否则输入框会失焦）；Toast 用 `role="status"` 播报；重渲染后会还原原来聚焦的贴纸

## 下载安装

1. 打开本仓库右侧 **Releases**，下载 `TheJourney-mac.zip`
2. 解压得到 `TheJourney.app`，拖进 `/Applications` 或双击打开
3. 首次打开如被拦截（应用无付费签名）：**右键 → 打开 → 打开**，确认一次即可，之后双击正常启动
4. 需要 macOS 12 及以上，Intel / Apple Silicon 通用

## 自己构建

```bash
bash desktop/build.sh
```

需要 Xcode 命令行工具。产物在 `desktop/TheJourney.app`。

## 测试

```bash
node --test tests/app.test.mjs
```

网页层为了保持单文件零依赖，不能拆成外部 ES module，所以 `index.html` 里用
`PURE-CORE-START` / `PURE-CORE-END` 两个注释标记圈出一块**不碰 DOM 的纯逻辑区**。
`tests/harness.mjs` 用 `node:vm` 把这块真实代码取出来执行并命名导出，测试因此直接跑在
发布代码上——不存在需要手工同步的第二份实现。

往这块区域加函数时请注意：保持不引用 `document` / `localStorage` / 全局可变状态，
否则 harness 会取不到符号并直接报错。

## 说明

- 网页层是零依赖单文件 `index.html`（浏览器直接打开也能用）
- 桌面壳是 Swift + 系统 WKWebView（`desktop/main.swift`），Universal 二进制
- 数据存在本机 localStorage；应用内每次改动会防抖 3 秒触发原生层写文件级备份（`~/Library/Application Support/TheJourney/backups/`，保留最近 10 份）；另有 `stickyboards-v1-backup` 保存最近一次状态。应用不依赖网络（除加载在线手写字体）
