# The Journey · 便利贴白板

一个本地优先的 Mac 工作台：固定 2400×1600 画板、多画板、彩色便利贴、任务管理、图片和结构化文本都在同一个界面完成。数据默认只保存在本机。

## 功能

- 固定尺寸画板：每个画板都是 2400×1600，新建画板也使用同一尺寸，拖动和缩放不会跑出边界
- 文字排版：段落、换行、无序/有序列表、标题、引用、粗体、斜体、行内代码、链接；代码块支持关键字、字符串、数字和注释高亮，并识别 ``` 围栏代码块
- 画布工具：真正的框选、多选、左/右/顶/底对齐、横纵居中、均匀分布、编组、锁定、置顶/置底、箭头、自动吸附连接线、矩形、圆形（含填充色与文字标签）、手绘和可编辑表格
- 图片：剪贴板粘贴、PNG 透明通道保留、裁剪位置/缩放、替换、预览和图片标注
- 任务：状态、优先级、标签、截止日期、提醒、重复任务、子任务状态、依赖关系（含循环依赖保护）和目标归属
- 视图：真看板（拖拽改状态）、日历（月历/列表切换）、跨画板全局搜索一键跳转并自动居中定位、状态/优先级/标签筛选、统计仪表盘（含子项完成口径）
- 层级与计划：目标 → 阶段 → 里程碑树形展示与自动进度汇总、Playbook 和复盘模板、每日/每周计划、习惯 streak
- 数据安全：撤销/重做（⌘Z / ⇧⌘Z）、便利贴与画布元素统一回收站（可恢复/清空）、JSON 导入/导出、多选批量编辑、文件级自动备份
- 快捷键：⌘Z 撤销、⇧⌘Z 重做、⌘D 复制、⌘A 全选、Delete 移入回收站、方向键微调（Shift 大步长）、Esc 取消工具

## 下载安装

1. 打开本仓库右侧 **Releases**，下载 `TheJourney-mac.zip`
2. 解压得到 `TheJourney.app`，拖进 `/Applications` 或双击打开
3. 首次打开如被拦截（应用无付费签名）：**右键 → 打开 → 打开**，确认一次即可，之后双击正常启动
4. 需要 macOS 12 及以上，Intel / Apple Silicon 通用

## 自己构建

```bash
bash desktop/build.sh
```

需要 Xcode 命令行工具。产物在 `desktop/TheJourney.app`。

## 说明

- 网页层是零依赖单文件 `index.html`（浏览器直接打开也能用）
- 桌面壳是 Swift + 系统 WKWebView（`desktop/main.swift`），Universal 二进制
- 数据存在本机 localStorage；应用内每次改动会防抖 3 秒触发原生层写文件级备份（`~/Library/Application Support/TheJourney/backups/`，保留最近 10 份）；另有 `stickyboards-v1-backup` 保存最近一次状态。应用不依赖网络（除加载在线手写字体）
