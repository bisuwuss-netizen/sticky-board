# Sticky Board 便利贴白板

一个本地优先的 Mac 工作台：固定 2400×1600 画板、多画板、彩色便利贴、任务管理、图片和结构化文本都在同一个界面完成。数据默认只保存在本机。

## 功能

- 固定尺寸画板：每个画板都是 2400×1600，新建画板也使用同一尺寸，拖动和缩放不会跑出边界
- 文字排版：段落、换行、无序/有序列表、标题、引用、粗体、斜体、行内代码、链接；代码块支持关键字、字符串、数字和注释高亮
- 画布工具：真正的框选、多选、左/顶/横纵居中、横纵向均匀分布、编组、锁定、置顶/置底、箭头、自动吸附连接线、矩形、圆形、手绘和可编辑表格
- 图片：剪贴板粘贴、PNG 透明通道保留、裁剪位置/缩放、替换、预览和图片标注
- 任务：状态、优先级、标签、截止日期、提醒、重复任务、子任务状态、依赖关系、父任务和目标归属
- 检索和视图：跨画板搜索、一键跳转、状态/优先级/标签筛选、看板、时间线、月历和统计仪表盘
- 计划体系：每日/每周计划、周复盘模板、习惯 streak、目标→阶段→里程碑→任务的自动进度汇总、Playbook 和复盘模板
- 数据安全：撤销、回收站、JSON 导入/导出和自动备份

## 下载安装

1. 打开本仓库右侧 **Releases**，下载 `TheJourney-mac.zip`
2. 解压得到 `TheJourney.app`，拖进 `/Applications` 或双击打开
3. 首次打开如被拦截（应用无付费签名）：**右键 → 打开 → 打开**，确认一次即可，之后双击正常启动
4. 需要 macOS 12 及以上，Intel / Apple Silicon 通用

## 自己构建

```bash
bash desktop/build.sh
```

需要 Xcode 命令行工具。产物在 `desktop/TheJourney.app`。

## 说明

- 网页层是零依赖单文件 `index.html`（浏览器直接打开也能用）
- 桌面壳是 Swift + 系统 WKWebView（`desktop/main.swift`），Universal 二进制约 750K
- 数据存在本机 localStorage，并在 `stickyboards-v1-backup` 保存最近一次自动备份；应用不依赖网络（除加载在线手写字体）
